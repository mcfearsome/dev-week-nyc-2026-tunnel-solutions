# Project Overview

## Project Name

### tunnel.solutions

## Elevator Pitch

A capability-scoped, ephemeral tunnel that *understands the protocol it carries*. Open a disposable, scoped door to your local MCP server — share exactly the tools you allow, for exactly as long as you allow — and it evaporates on close or TTL. The same primitive powers **tnls**: send a large file to a teammate over BitTorrent through a scoped link, so the bytes move peer-to-peer (you don't eat the bandwidth) while the tunnel gates who can fetch and for how long.

**Live at https://tunnel.locker** · Rust · no inbound ports · the relay holds no secret and no state.
